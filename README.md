 在提问之前
在你准备要通过电子邮件、群组或者聊天室提出技术问题前，请先做到以下事情：
1）尝试在你准备提问的论坛的旧文章中搜索答案。
2）尝试上网搜索以找到答案。
3）尝试阅读手册以找到答案。
4）尝试阅读常见问题文件（FAQ）以找到答案。
5）尝试自己检查或试验以找到答案。
6）向你身边的强者朋友打听以找到答案。
7）如果你是程序开发者，请尝试阅读源代码以找到答案。
